2. 项目概述

Antenna Post-Processor 从 EMQuest 测试系统导出的 *_merged.csv 计算车企要求的各项天线指标，填入 Excel 模板并自动生成 3D 辐射方向图。

运行方式

# 图形界面 (PySide6, 主题 dark_teal) python main.py # 命令行批处理 python -c " from src.pipeline import run_batch_pipeline run_batch_pipeline('data/5G1_merged.csv', 'data/template_5G1.xlsx', 'output/result.xlsx') " # 打包为 .exe pyinstaller antenna_post_processor.spec

技术栈: Python 3.8+ · NumPy · PySide6 (GUI) · openpyxl · Matplotlib · Qt Designer · i18n (中/英)

1. 快速上手（操作指南）

1.1 单文件模式

1 选择输入文件 — 点击 浏览... 按钮（📂 文件设置 Tab → 输入文件），选择 .csv 或 .xlsx 数据文件。

2 选择模板 — 点击第二个 浏览...，选择模板 Excel（.xlsx）。选择后自动识别 LAG 列配置。

3 确认 LAG 设置 — 切换到 📐 LAG 配置 Tab，确认快捷角度按钮和已配置项。可按需添加自定义角度或范围。

4 选择外推 — 勾选 Theta 外推到 180° 复选框（默认关闭）。外推会使 Directivity 降低约 0.04 dB，更接近 IEEE 标准全空间积分。

5 开始处理 — 点击 ▶ 开始处理 按钮。进度条显示读取/计算/写入三阶段进度。完成后结果 CSV 自动导出到 ~/Downloads/。

6 查看结果 — 输出 Excel 在输出目录中生成，每个 Sheet 填入对应频点的计算值。

1.2 多文件批量模式

1 添加数据文件 — 点击 📂 添加数据文件...（可在文件对话框中 Ctrl+点击多选），支持 .csv 和 .xlsx 混合选择。

2 选择模板 — 选择包含多个工作表（如 5G1~5G4）的模板 Excel。

3 自动匹配 — 点击 🔗 自动匹配 按钮，软件自动将工作表名与数据文件名按命名键匹配（如 "5G1" ↔ "G1FinalSummary.xlsx"）。

4 检查匹配 — 匹配表中每行显示 [工作表 | 数据文件（下拉可选） | 状态]。绿色 ✓ 表示已匹配，可手动调整下拉框覆盖自动匹配。

5 工作表命名 — 匹配表右侧的 工作表名: 下拉框可选择命名方式：保留原模板工作表名（默认）或 用数据源名替换。选择"用数据源名替换"时，输出 Excel 的工作表名将使用数据源文件的键名（如 "G1FinalSummary"），而非模板中的原始工作表名。

6 开始处理 — 点击 ▶ 开始处理，每个工作表使用自己的数据源独立计算，结果写入同一个输出 Excel。

2.1 输入: EMQuest 合并 CSV

  • Phi (方位角): 0–359°, step 1° (360 点)

4. 多文件批量处理

4.1 适用场景

当模板包含多个工作表（如 5G1、5G2、5G3、5G4），每个工作表对应不同天线的测试数据时使用。例如：

模板工作表数据文件匹配键
5G1G1FinalSummary.xlsxG1 ↔ G1
5G2G2FinalSummary.xlsxG2 ↔ G2
5G3G3FinalSummary.xlsxG3 ↔ G3
5G4G4FinalSummary.xlsxG4 ↔ G4

4.2 匹配算法

三步匹配策略，可手动覆盖：

# 步骤 1：提取键 "5G1" → extract_key() → "G1" "G1FinalSummary.xlsx" → extract_key() → "G1" # 步骤 2：精确匹配（键相等 → 置信度 1.0） "G1" == "G1" → 匹配 ✓ # 步骤 3：回退匹配（第一个未匹配工作表 ← 第一个未使用文件 → 置信度 0.5）
提示：如果自动匹配不正确，可以在匹配表每行的下拉框中手动选择正确的数据文件。

4.3 多源处理逻辑

每个工作表使用独立的数据源和独立的 LAG 配置：

  • 工作表 5G1 读取 G1FinalSummary.xlsx → 自己的频率列表 → 自己的列结构
  • 工作表 5G2 读取 G2FinalSummary.xlsx → 自己的频率列表 → 自己的列结构
  • 如果一个工作表没有匹配到数据源，会被跳过（日志中显示警告）

4.4 工作表命名方式

匹配表右侧的 工作表名: 下拉框提供两种命名方式：

选项行为适用场景
保留原模板工作表名输出 Excel 工作表名 = 模板中的原始工作表名（如 5G1、5G2）模板工作表名有固定业务含义
用数据源名替换输出 Excel 工作表名 = 数据源文件的提取键名（如 G1FinalSummary、G2FinalSummary）希望输出工作表名直接反映数据来源
提示：切换命名方式会自动重建匹配表显示。未匹配的额外数据源始终使用数据源文件名命名，不受此选项影响。

5. 处理流程

1 CSV 流式索引 — 扫描 section header 和频点位置，构建字节偏移表 (src/parser.py)

2 模板列头解析 — 正则识别 Frequency / Directivity / Gain / LAG 列，自动生成 LAG 配置 (src/lag_config.py)

3 逐频点计算 — 按 Sheet 频点列表，取 CSV 最近邻频点，计算全部指标 (src/calculator.py)

4 图表生成 — 3D 球面方向图 + 2D 极坐标 / 直角坐标切面 (src/plotter.py)

5 Excel 填充 — 保留模板格式，写入数值 + 嵌入 PNG (src/exporter.py)

公式 1 — 总增益 Gain (dBi)

1.1 双极化合成 Total Power

Theta 极化 Gθ 和 Phi 极化 Gφ (均为 dB) 在线性域合成总功率：

Gθ,lin(φ,θ) = 10 Gθ(φ,θ) / 10 Gφ,lin(φ,θ) = 10 Gφ(φ,θ) / 10 Gtotal,lin(φ,θ) = Gθ,lin(φ,θ) + Gφ,lin(φ,θ) [线性标度] Gtotal(φ,θ) = 10 · log10( Gtotal,lin(φ,θ) ) [dBi]

1.2 峰值增益

Gpeak = max { Gtotal(φ,θ) } for all φ ∈ [0, 359°], θ ∈ [0, 110°]

实现: src/calculator.py:compute_total_gain_linear() — NumPy 向量化，单频点计算 <1 ms。

公式 2 — 方向性 Directivity (dBi)

2.1 球面积分

U(φ,θ) = Gtotal,lin(φ,θ) [辐射强度, 线性] Prad = ∫02π ∫0π U(φ,θ) · sin(θ) dθ dφ

2.2 数值积分（均匀网格）

Δθ = π / (Nθ − 1) [弧度] Δφ = 2π / Nφ [弧度] Prad ≈ Σi=0Nφ−1 Σj=0Nθ−1 U(φi,θj) · sin(θj) · Δθ · Δφ

2.3 方向性

Dmax = 10 · log10 ( 4π · Umax / Prad ) [dBi]

其中 Umax = max{U(φ,θ)}。

注意: 当前数据仅覆盖 Theta 0–110°，未做外推。对背部 (110–180°) 的忽略会导致 Directivity 略微高估。如需精确值，可在 pipeline 中启用外推。

实现: src/calculator.py:compute_directivity() — NumPy broadcast，Δθ = π/(111−1)，Δφ = 2π/360。

公式 3 — 效率 Efficiency

3.1 辐射效率

ηdB = Gpeak − Dmax [dB] η% = 10 ηdB / 10 × 100 [%]

物理含义: η < 100% (即 ηdB < 0) 表示存在导体损耗、介质损耗或阻抗失配。理想无损天线 Gpeak = Dmax，η = 100%。

实现: src/calculator.py:compute_efficiency()

公式 4 — LAG 局部方位面增益

4.1 定义

LAG (Local Azimuth Gain) = 固定俯仰角 θ 上，方位面 0–360° 扫描的线性域平均增益。用于评估天线在"某个仰角圈"上的覆盖能力。

4.2 单俯仰角 LAG

LAG(θ) = 10 · log10( (1 / Nφ) · Σi=0Nφ−1 Gtotal,lin(φi, θ) ) [dB]

关键: 在线性域做平均（先 10^(dB/10) 转线性，求和取均值，再转回 dB），而非直接在 dB 域求算术平均。

4.3 俯仰角范围 LAG

LAG(θ1→θ2) = (1 / Nθ) · Σθ∈[θ₁,θ₂] LAG(θ) [dB]

范围 LAG 在 dB 域 对各切片取均值。典型输出:

  • LAG(0→90°) — 上半球面覆盖能力
  • LAG(60→90°) — 低仰角覆盖能力（车载天线关键指标）
  • Theta=60/70/80/90 — 指定俯仰角切片的 LAG 值

4.4 LAG 配置自动检测

模板 Excel 列头中正则匹配以下格式的列，自动提取单角度和范围配置：

公式 5 — 轴比 Axial Ratio (Stokes 参数法, IEEE 149)

5.1 复电场分量

|Eθ| = 10 Gθ / 20 [场强幅值, 线性] |Eφ| = 10 Gφ / 20 [场强幅值, 线性] Eθ = |Eθ| · e j · φθ [复电场, θ 分量] Eφ = |Eφ| · e j · φφ [复电场, φ 分量]

其中 φθ、φφ 分别为 Theta Phase 和 Phi Phase 的弧度值。

5.2 Stokes 参数

S0 = |Eθ|² + |Eφ|² [总功率] S1 = |Eθ|² − |Eφ|² [θ vs φ 功率差] S2 = 2 · Re( Eθ · Eφ* ) [±45° 线极化分量] S3 = 2 · Im( Eθ · Eφ* ) [圆极化分量]

其中 Eφ* 为复共轭。S3 > 0 表示右旋圆极化 (RHCP)，S3 < 0 表示左旋圆极化 (LHCP)。

5.3 极化椭圆半轴

Spol = √( S1² + S2² + S3² ) [极化功率] |Emajor|² = ( S0 + Spol ) / 2 |Eminor|² = ( S0 − Spol ) / 2

5.4 轴比

ARlinear = |Emajor| / |Eminor| ARdB = 20 · log10( ARlinear ) [dB]

物理含义: AR = 0 dB → 理想圆极化；AR → ∞ (大值) → 纯线极化。|S3|/S0 越接近 1 极化越"圆"。

Stokes 法优势: 相比直接求解椭圆方程（易出现 C²≈0 的数值不稳定），Stokes 参数法通过 S1²+S2²+S3² 恒正保证了数值稳定性。参考 IEEE Std 149-2021 §C.2。

实现: src/calculator.py:compute_axial_ratio() — NumPy 向量化，输出 (360, 111) AR 矩阵。

12. Theta 外推选项

12.1 背景

EMQuest 测量数据通常只覆盖 Theta 0–110°（部分球面）。标准天线计算公式（如 Directivity 球面积分）需要全空间 0–180° 数据。

12.2 不外推 vs 外推

不外推（默认）外推（勾选开关）
积分范围0–110°0–180°
Directivity 偏差~0.0007 dB（与人工计算对比）~0.04 dB 差异（补入了背部能量估计）
物理合理性假设背部辐射为零（高估 D）尾部 10 点线性回归外推（IEEE 推荐）
适用场景方向性天线（前后比 > 20 dB）低方向性天线、需对标准全空间积分

12.3 外推算法

# LogMag 数据：逐 φ 独立线性回归（尾部 10 点） slope = (n·Σxy - Σx·Σy) / (n·Σx² - Σx²) ← 最小二乘斜率 约束：slope > 0 时归零（增益不上升） 外推值 ≤ 最后一点（不超出末端的实测值） 外推值 ≥ 峰值 - 40 dB（不超过 40 dB 动态范围） # Phase 数据：尾部 10 点平均值填充（常数法） phase_extrap = mean(phase[-10:]) ← 相位无趋势，填均值最安全

12.4 使用建议

  • 车载鲨鱼鳍天线（前后比 > 20 dB）：不勾选外推，差异可忽略
  • 基站天线（较低方向性）：建议勾选，使 Directivity 更接近真实值
  • 不确定时：用两个选项各跑一次，比较结果。如果 Directivity 差异 < 0.05 dB，外推影响可忽略

15. AI 智能辅助识别

本工具内置云端/本地 LLM 智能辅助功能，可作为规则匹配的兜底方案，在以下场景自动辅助识别：

场景说明

20. 模板识别工具

通过 工具 → 模板识别... 打开。用于检测和自定义模板 Excel 的列头识别规则。

使用流程：

  1. 浏览选择模板 Excel 文件，点击「检测」
  2. 自动扫描所有工作表的列头，显示检测类型
  3. 可通过下拉框手动修改类型（43 种可选）
  4. 点击「重检」对单列重新自动分类
  5. 点击「💾 保存到配置文件」写入 config/column_patterns.json

关键功能：

  • 工作表下拉框切换不同 Sheet
  • 标题行微调框调整列头行号
  • 检测结果摘要：共 N 列，识别 M 列
  • 保存的 JSON 模式优先级高于内置正则

23. 报告列配置

完整报告（独立文件）的列顺序和表头可通过 config/full_report_columns.json 自定义。

配置内容：

  • 22 种列类型定义（key / 中英文表头 / 数值格式 / 是否必需）
  • LAG/AR 角度的动态列模板（支持 {angle}/{start}/{end} 占位符）

  • 验证警告不阻止报告生成，仅在日志中提示
