1. 反复出现的问题及根因分析

#1 反复 6 次 GUI 布局损坏 — widget 被压缩/重叠/不可见

现象：文件列表太窄看不清、输出框被挤没、匹配表文字重叠、LAG 配置项上下粘连。
每次修复：调一个具体数字（maxHeight=65→100、间距 3→4），修好这个坏那个。
真正根因：tabFile / tabLag 是普通 QWidget，内容多了 Qt 自动压缩所有子控件。 只有最后一次修复（包进 QScrollArea）才解决了根因。

#2 反复 4 次 git checkout 丢失代码 — 再通过正则补回去产生语法错误

现象：git checkout -- ui/main_window.py 抹掉 ~400 行多文件 UI 代码。 用 Python 正则脚本重注入，导致 f-string 括号不匹配、layout null-check 丢失。 每次修复：手工数括号、补 null-check。
真正根因：手写代码和编译 UI 紧耦合但没有隔离层。没有 diff 验证步骤。

#3 反复 3 次 线程/signal 不完整 — 点 Start 无反应

现象：_on_start() 创建了 QThread + ProcessingWorker 但缺少 moveToThread()、信号连接、thread.start()。
每次修复：手工加回缺失的 7 行代码。
真正根因：线程启动是一个多步骤协议（create → move → connect → start），但没有封装成单一方法或 hook。代码补丁不完整时无自动检测。

#4 反复 2 次 FormLayout FieldRole/LabelRole 错乱

现象：编译后的 UI 文件有 8 处用了 LabelRole 而非 FieldRole， 导致 "Cell already occupied" 警告和布局错位。
真正根因：Qt Designer → pyuic 编译过程中 form layout 角色标记错误。 没有自动检查 form layout 完整性的步骤。

#5 反复 2 次 EXE 体积膨胀 — 从 73MB 涨到 187MB

现象：spec 文件在迭代中丢了 excludes 列表 + 加了冗余 hiddenimports， WSL 环境的 chromadb/openai/huggingface 等包被自动拉入。
真正根因：没有 EXE 体积门禁。没有 spec 文件 diff/review 流程。

#6 反复 3 次 测试与新 UI 脱节 — 改 UI 后测试挂掉

现象：隐藏 editCsvPath 后 5 个测试失败。测试引用了已删除的方法 _on_browse_csv()。
真正根因：测试与 widget 名称紧耦合。没有 "UI 契约测试" 来验证 widget 存在性/可见性。

2. 为什么这些问题难以发现和修复

机制缺陷后果影响的问题
无 GUI 布局自动化验证 只看代码看不出 widget 是否被压缩 #1, #4
无 git 操作前后 diff 检查 checkout/rebase 丢代码后无人察觉 #2, #3
线程创建无封装/无 hook 每次都手工写 7 行协议代码，缺一行就挂 #3
无 EXE 体积回归检测 体积翻倍才发现 #5
无 spec 文件变更审查 删了 excludes 没人知道 #5
测试用旧 widget 名硬编码 改 UI 后测试批量挂 #6
无 E2E "点 Start 看结果" 测试 线程不启动这种致命 bug 在手工测试才发现 #3

3. 质量保障体系

三层门禁模型

层级检查内容触发时机阻塞级别
L1 语法 + 导入 + 单元测试 每次保存 / 每次修改后 GATE — 不通过不能继续
L2 GUI 布局完整性 + FormLayout 角色 + widget 可见性 + 线程信号连接 修改 UI 代码后 GATE — 不通过不能提交
L3 EXE 体积 + spec 文件 diff + E2E 冒烟 打包前 / 提交前 GATE — 不通过不能发布

Harness 1: GUI 完整性守护

设计目标：任何 GUI 代码变更后，自动验证以下 6 项：

  1. FormLayout 角色检查 — 扫描编译 UI 文件，确保每个 setLayout(row, FieldRole, ...) 前有对应的 setWidget(row, LabelRole, ...)
  2. Widget 存在性检查 — 实例化 MainWindow 后，关键 widget（_file_list_widget, _match_table, editOutputName, btnStart）不为 None
  3. Widget 可见性检查 — 不应隐藏的 widget 未隐藏（如 editOutputName），应隐藏的已隐藏（如 editCsvPath）
  4. 最小尺寸检查 — 关键 widget 的 minimumHeight/minimumWidth > 阈值
  5. 信号连接检查 — btnStart.clicked 连接到 _on_start，_on_start 内 thread.started 连接到 worker.run
  6. ScrollArea 包装检查 — tabFile 和 tabLag 的内容已包在 QScrollArea 中
# 触发方式
python3 gui_integrity_check.py          # 完整检查
python3 gui_integrity_check.py --quick  # 仅 L1+L2 (10s)

Harness 2: 打包体积门禁

设计目标：EXE 体积不超过预算，spec 文件变更有审查。

  1. 体积上限 — Windows ≤ 80MB，Linux ≤ 110MB
  2. 体积趋势 — 每次构建记录体积，超出上次 10% 时告警
  3. Spec diff — 对比当前 spec 与基线（已知良好版本），标记新增/删除的 hiddenimports 和 excludes
  4. 污染包扫描 — 检查 TOC 中是否出现 pandas/sqlalchemy/pydantic/torch 等禁用包
# 触发方式
python3 build_size_gate.py              # 构建后自动运行
python3 build_size_gate.py --baseline   # 更新基线

Harness 3: E2E 冒烟自动化

设计目标：验证 "加载数据 → 点 Start → 出结果" 完整链路。

  1. 数据源加载 — DataSource.from_path() 正常打开 CSV 和 FinalSummary
  2. 管线运行 — run_pipeline() 产生 ≥ 预期行数的结果
  3. GUI 线程启动 — 创建 MainWindow → 模拟点击 Start → 验证 _running=True 且 thread.isRunning()
  4. 输出文件 — 生成的 Excel 文件存在且大小 > 0
# 触发方式
python3 _e2e_verify.py                  # 完整 E2E
python3 _e2e_verify.py --quick          # 仅管线（不启动 GUI）

# G3: 信号链路检查
def _check_signal_chain(source_code: str) -> List[str]:
    errors = []
    # 1. btnStart 必须连接 _on_start
    if "self.ui.btnStart.clicked.connect(self._on_start)" not in source_code:
        errors.append("MISSING: btnStart.clicked → _on_start")
    # 2. _on_start 必须创建 thread + worker
    if "QThread(self)" not in source_code:
        errors.append("MISSING: QThread creation in _on_start")
    # 3. 必须有 moveToThread
    if "moveToThread" not in source_code:
        errors.append("MISSING: worker.moveToThread(thread)")
    # 4. 必须连接 started → worker.run
    if "self._thread.started.connect(self._worker.run)" not in source_code:
        errors.append("MISSING: thread.started → worker.run")
    # 5. 必须 thread.start()
    if "self._thread.start()" not in source_code:
        errors.append("MISSING: thread.start()")
    return errors

# S3: 污染包扫描
FORBIDDEN = ['pandas', 'sqlalchemy', 'pydantic', 'torch', 'chromadb',
             'openai', 'huggingface', 'tokenizers', 'transformers', 'tqdm', 'rich']
def check_toc_clean(toc_path: str) -> List[str]:
    with open(toc_path) as f:
        content = f.read()
    found = [pkg for pkg in FORBIDDEN if pkg in content]
    return found  # 任何匹配都是 GATE 失败
